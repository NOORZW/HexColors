How a hex code works

A hex code is a color written as #RRGGBB. The first pair is red, the second is green, and the third is blue.

Each pair is a number from 00 (none) to FF (all of it). Hex counts with 16 symbols: 0 to 9, then A to F.

Example: #FF8800 is FF red, 88 green and 00 blue. That makes orange.

HexNumberMeaning
000None
0A10A little
1016One step up the left digit
80128About half
FF255All of it

When all three pairs match, you get gray.
